モジュール設定

ソケットに装着したモジュールを選んで保存します。保存した側をリセットすると、選んだモジュールで起動します。

  1. 接続親機を USB か無線でつなぐ
  2. 選択モジュールを選んで保存
  3. リセット保存した側をリセット

キーボードの親機を接続してください。

接続方法
USB
親機をデータ通信対応ケーブルで接続します。PC は Studio 用ポートを選びます。Android は USB デバイスを選択し、アクセスを許可してください。Android でシリアルポートの画面が開く場合は USB デバイス選択に切り替えてください。
無線
親機を接続待ちにして「無線接続」を押します。候補が多いときは、端末の設定に表示される機器名の先頭を、大文字・小文字も合わせて入力してください。CaGiMe が候補に出ないときは、標準配列の左側で Esc を押しながら U を押します。
左右
左右どちらを設定する場合も、接続先は親機です。子機側を設定するときは、左右の電源を入れて通信できる状態にしてください。
