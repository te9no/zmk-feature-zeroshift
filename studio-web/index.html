接続方法

USB は親機をデータ通信対応ケーブルで接続します。Android は USB デバイスを選択し、アクセスを許可してください。PC は Studio 用ポートを選びます。Android でシリアルポートの画面が開く場合は USB デバイス選択に切り替えてください。無線では親機を接続待ちにして「無線接続」を押します。候補が多いときは、端末の設定に表示される機器名の先頭を、大文字・小文字も合わせて入力してください。

CaGiMe が無線の候補に出ないときは、標準配列の左側で Esc を押しながら U を押します。
